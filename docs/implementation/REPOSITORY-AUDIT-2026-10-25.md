## הגנות, תיקיות והמשך

קריאה מ־GitHub ב־25.10 אימתה ש־main מוגן ושארבעת required checks הם
`python-tests`, ‏`coverage-gate`, ‏`web-tests`, ‏`static-checks`. הגדרת rulesets
ריקה אינה היעדר הגנת branch קלאסית. לחשבון הנוכחי יש push ואין admin;
קריאת כל פרטי ההגנה המנהליים החזירה 404. לא שונו או נחלשו הכללים.

תיקיות: `vmi-d1-overlay` מחזיקה main נקי; `vmi-d1-trace` את PR #12;
`vmi-session-review` את תיקוני הביקורת; `vmi-d1-clock` את סיכום הניקוי.
התיקייה `Visual-Match-Intelligence` נשארת כרגע ב־2D הישן עד בחירת המשתמש.
לא מציגים בדיקת UI של ענף התלת־ממד כאילו היא תצוגת main.

לא מורצים מחדש snapshots ישנים של ענפים ששולבו רק כדי לקבל אותם ירוקים:
בודקים את התוצאה המשולבת העדכנית ואת ההפרש הפעיל של PR #12. בדיקת הכשל
ההיסטורית ב־PR #2 והכשל המכוון ב־PR #14 אינם רגרסיות פתוחות ב־main.
קבלת הגרפיקה והאנימציה בחזון, הכרעת מודל D2-00 ופריסה D2-06 נשארות
בסטטוס האמיתי שלהן; סידור Git אינו משלים אותן.
