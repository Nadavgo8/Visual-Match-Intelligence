# D1 — דמו נגיש מתוך המימוש הקיים

החידוד האחרון הוא תנאי הקבלה: צפייה נגישה, נקייה ומשכנעת בתלת־ממד
הקיים, בעיקרSeed2. אין דרישה לפיזיקה מסחרית, מנוע חדש או הצגת90 דקות.
הדוגמאות הן מקרי בדיקה מייצגים, לא רשימת אירועים סגורה. האפליקציה
והפרשנים נשארים באחריות הנפרדת שלהם.

| תחום | קיים בפועל | פער ממוקד |
| --- | --- | --- |
| תלת־ממד | שלד אנושי, כדור, אצטדיון, מצלמת שידור וגיבוי WebGL ב־PR #12 | חיבור מגע/כיוון/gait ממקור2.5 אחרי מיזוג ו־B4; בדיקה בתנועה |
| כדורגל | 4‑3‑3 ב־teams.py, תמיכה ורוחב ב־motion.py, מסלולי C1 ומגעים ב־PR #32 | מוסר→כדור→מקבל, בעיטה/נגיחה, עצירה וחידוש; תנוחת הכנה לפני המגע עדיין חסרה |
| ניווט | פרקים קיימים, Room.seek ו־Replay.advance | הורחבו פרקי צהוב ונבדל; משתמשים ב־pause הקיים אחרי ההשלכות |
| קהל ואווירה | שלוש תנוחות לפי C שנמסר, שני פסים זהים ו־A=0.8C+0.2T | אימות חזותי של עוצמות שונות, שקט בזמן התקפה ומידע חסר; אין תגובה מומצאת בגלל שער |
| מומנטום | חלון420 שניות ומעבר400ms | תיקון3.25 עוצר זחילה לאחר pause/seek/reset/ניתוק/missing; החישוב נשמר |
| סנכרון | run_id, snapshots, דחיית נתונים ישנים וסינון לפי זמן פריים | קבלה חזותית של הצרכן והמקור המשולבים עדיין נדרשת |

בוחרים חלונות מאותו replay: כ־10–20 שניות לפני אירוע וכ־10 אחריו,
ומאריכים כשצריך לראות חידוש. שער, עבירה/צהוב, נבדל ושינוי מומנטום הם
מקרי המינימום; מסירות, קרן, נשיאה והצלה משולבות כפי שכבר נוצרו במשחק.
seek בונה היסטוריה בשקט; אין לאפס מומנטום כדי לייצר דרמה בקטע קצר.
הניווט נשאר בכלי המציג. צהוב נשאר בפרטי האפליקציה, וסמל עבירה יחיד ב־TV.

תרחישי החוזה ב־scenarios.py כוללים קפיצות setup ואינם ראיה לרציפות
חזותית. נבדל אקראי אינו הוכחת גאומטריה: הקטע הנבחר חייב להיבדק בזמן
המסירה מול הכדור והמגן השני ובמעורבות אמיתית. זה פער מהותי פתוח.

מקור2.5 ב־PR #32 ננעל ל־2–0 עם שער מבוטל מקושר; הוא עדיין אינו המקור
הממוזג או השרת הפעיל. השוואה מבודדת נתנה16.81s לחדש מול18.36s לישן,
עם אותם אירועים ומיקומים; אין ראיה להאטה פי ארבעה. טעינת seed קרה עדיין
סינכרונית והיא סיכון לאינטגרציה. לא נבנה מנוע חלופי כדי לפתור זאת.

המשך: תיקון כשל סיבתיות האירועים היחיד ב־CI של המקור → שערים ו־B4 →
חיבור תנוחות המגע לתלת־ממד → אימות נבדל ורצפי משחק/קהל/מדדים יחד.
מתקנים פערים שמשנים קריאות או אמינות, בלי הרחבת מערכות האפקטים.

ראיות נוכחיות: CI שלf9e10ab הסתיים ב־584PASS/1FAIL בקישור ניתוח שער
לפריט הזדמנות. חישוב הכיסוי המקומי מהדוח המלא עבר95.58%/91.41%, אך
ה־CI כולו אינו PASS. אימות חזותי חדש חסום בחיבור בקרת הדפדפן; אין
טענת קבלת מראה/FPS חדש ואין בקשת מדידה ידנית חוזרת מהמשתמש.

פרקי המציג מהאפליקציה;176 בדיקות Node עברו ב־1.55s; Ruff ו־whitespace
עברו. בדיקות המומנטום מפעילות את tv.js ופונקציות המד בתוך DOM harness,
