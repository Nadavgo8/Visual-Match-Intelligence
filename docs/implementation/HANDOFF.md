## הרשאה ומצב

המשתמש אישר לבצע את מסלול מפתח 1, D1-01 עד D1-05, כולל בדיקות מחמירות, סקירת קוד, תיקונים, commit מפורט, push, PR ומיזוג אוטומטי בסשן. אין דרישת אישור אנושי שגרתית. אין לעקוף כללי שרת או להמציא סקירה עצמאית. חריגי עלות, הרשאה, החלטת מוצר וחוזה משותף נשארים בתוקף. המשתמש כבר בחר בחוזה v2 ובמעבר מתואם של כל המפיקים והצרכנים באותו PR — אין לשאול שוב על אותה בחירה.

PR #1 (נוהל) ו־PR #3 (שוער ושחזור) מוזגו. main האחרון שאומת לפני ההמשך: 2bc616a9c3b0b2de03fa1dc94ba903428fb701fe, 42 בדיקות עברו גם אחרי המיזוג. PR #2 נסגר כמוחלף ב־#3.

## עבודה נוכחית

ענף: codex/d1-generator-core. תלויות מוזגו; ה־main שולב בענף בלי שכתוב היסטוריה. D1-01 v2 מומש עם מעבר הצרכנים באותה יחידת עבודה; לא התחיל D1-02. פרטי החוזה ב־[D1-01-CONTRACT-PROPOSAL.md](D1-01-CONTRACT-PROPOSAL.md), למרות השם ההיסטורי ההכרעה כבר מאושרת.

קבצים: generator analytics/state/motion/export, מעטפת חוזה, MatchModel וקישורים, Attention Engine, חבילות עובדות, tools/qa/templates, API ו־tests. אין שינוי ספק מודל, תלויות או תצורת ענן. ייצוא JSONL מלא נשאר כלי נתונים למפתחים; פרשן ואפליקציה אינם מקבלים תוצאת סיום או פרקים עתידיים בהודעות המצב שלהם. הרשאות חדרים ו־run_id עדיין D2-02.

בדיקות עדכניות וסקירה מפורטות ב־[לוח העבודה](10-WORK-BOARD.md). 83 בדיקות עברו לפני התיקון האחרון; 38 בדיקות ממוקדות עברו לאחריו. 101 seeds ושני ניסויי mutation עברו כמצופה. אחרי commit יש להריץ שוב על SHA המדויק, לתעד סקירת PASS אמיתית ולבדוק את התאמת בסיס origin/main. אין לסמן DONE לפני מיזוג ואימות main. מספר PR, final SHA ופלטי אימות סופיים יופיעו ברשומת ה־PR.

## פקודת הרצה בפועל

מתוך שורש הריפו, PowerShell:

```powershell
$env:VMI_OFFLINE = '1'
$env:VMI_WARM_DEMO = '0'
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
Remove-Item Env:APPLICATIONINSIGHTS_CONNECTION_STRING -ErrorAction SilentlyContinue
& "$env:TEMP/vmi-quality-baseline-20261022/Scripts/python.exe" -m pytest tests -q -ra --strict-markers --strict-config -p no:cacheprovider -W error
```

Python 3.12.13 בסביבה זמנית קיימת; לא מתקינים שוב ולא מניחים שתלויות נעולות. התקנת prerelease הזמנית וה־CI שעדיין חסר מתועדים בנוהל; הקמתם היא D2-01.

## הצעד הבא

לסיים ביקורת על השינוי, להריץ חבילה מלאה על ה־commit הסופי, לפתוח/לעדכן PR עצמאי ל־main ולמזג אוטומטית רק לאחר מעבר השערים ללא bypass. לאמת main, ואז לפתוח codex/d1-generator-scenarios מ־main המעודכן. לכל משימה PR נפרד; אין לבנות על ענף לא ממוזג. לשמור ראיות בלוח ובהעברה ולהמשיך אוטומטית במשימות שהתלויות שלהן הושלמו.
