# D1 — ביקורת תצוגה וקוד, 25.10.2026

המשך חד־פעמי של העבודה המורשית, ללא תזמון חדש. המכסה נבדקה לפני העבודה ואפשרה שימוש רגיל; לא נצרך קרדיט איפוס. המשימה הפעילה נשארת D1-04 בענף `codex/d1-match-3d`, בתיקיית `vmi-d1-trace`, וב־[PR #12](https://github.com/Nadavgo8/Visual-Match-Intelligence/pull/12). אין PR בדיקות נפרד. מחבר וסוקר: Codex, בשלבים נפרדים באותו סשן; אין טענה לביקורת עצמאית או אישור אנושי.

## בסיס ותחומי הביקורת

נקודת ההמשך הייתה `4455637`. בוצע fetch ושולב main ‏`7074cf5` באמצעות commit ‏`f96b599`. שילוב זה כולל את PRs ‏17–20 של השותף. בקונפליקט של בדיקות API נשמרו גם בדיקות נכסי התלת־ממד וגם בדיקת MIME של השותף. בלוח נשמרו מצב D1 הנוכחי ועדכוני D2. לא שונה חוזה או מימוש D2, ולא שוכתבה היסטוריה.

הסקירה כיסתה מקור וזמני מסירה, החזקה, analytics, מעקב עצל, נוסחת האווירה, גבולות טריות ויציבות, lifetime של סמלים, איפוס run, תנועת שחקנים ושלד, מיקום כדור, מצלמות, GPU ומשאבים, קהל והחלפת WebGL בגיבוי. נבדקו גם הבדיקות עצמן: ערכים צפויים עצמאיים, מסלולים שליליים, גבולות, בידוד מקור ואופן שימוש ב־fakes.

## בדיקות בפועל

- 100 seeds ‏`1..100`: ‏872,911 רשומות נבדקו לתקפות, ייחוד מזהים, קישורים ותוצאה סופית; 13,728 פריימים מדוגמים נבדקו לסגל פעיל, טווחים, גובה והחזקה. אפס הפרות; 72.42s. זהו audit של invariants מדוגמים, לא צפייה בכל פריים ולא soak.
- Node: ‏78 בדיקות עברו, אפס failures/skips, ב־4.60s בריצה המתועדת. החבילה המלאה כוללת גם בדיקות D2 שהגיעו מ־main; אין לייחס את כולן לקוד חדש של D1.
- Python מלא: 338 בדיקות עברו ב־412.83s, exit 0, עם הדרישות המחמירות שלהלן. אחרי הרחבת רשימת נכסי ה־HTTP הורצו שוב כל חמש בדיקות API: ‏5 עברו ב־18.54s. תוצאת החבילה על ה־SHA הסופי ב־CI נרשמת בנפרד ב־PR.
- mutation בזיכרון: המקור התקין ניקה מדידה ישנה; הסרת `onReset()` הותירה אותה והכשילה assertion. קוד ה־mutation לא נכנס למוצר.
- ruff ו־`node --check web/tv.js` עברו. בדיקת HTTP הורחבה ל־MatchScreen ולמודול המדדים, לרבות MIME של JavaScript.
- פקודות Python מלאות, SHA סופי, JUnit, ארבעת checks ותוצאת שער כיסוי נשמרים ב־PR. הרצה שעוד לא הסתיימה אינה PASS; תוצאות ה־SHA הקודם אינן מאשרות commit חדש. שער הכיסוי של Python אינו מודד כיסוי JS.

פקודת החבילה המקומית, Python 3.12 בסביבה המבודדת מהתלויות הנעולות, offline וחימום/telemetry כבויים:

```powershell
python -m pytest tests -q -ra --strict-markers --strict-config -p no:cacheprovider -W error --tb=short -o faulthandler_timeout=120 --basetemp=out/resume-pytest-temp-25 --junitxml=out/resume-python.xml

python -m tools.coverage_gate --coverage out/coverage.json --base origin/main
```

יש לבחור basetemp חדש בהרצה נוספת. כיסוי נמדד ב־CI עם `pytest_cov --cov --cov-branch`, וה־artifact וה־SHA מופיעים ב־PR; אין להשתמש בדוח ישן.

## בדיקות הדפדפן והקהל

תצוגת IAB עם Three.js מקומי ונכסים מקומיים בלבד. fixture זמני תחת out הפעיל את renderer האמיתי עם פריימים של כל 20 התרחישים; אין קוד fixture במוצר. נבדקו:

| קלט | תוצאה בפועל |
|---|---|
| C=0, T=1 | פסי A=20%; ‏crowdLevel=0, standing=0; אין הנפת ידיים בגלל התקפה |
| C=1, T=0 | פסי A=80%; ‏crowdLevel=1, standing=0.68; הנפת ידיים וקימה נגזרות מ־C |
| C חסר | unavailable, standing=0; שני הפסים במצב חסר, בלי להציג שקט מדוד |
| Reduce motion | מצלמה fixed; אין sway/הנפת ידיים; המדידה עצמה נשמרת |
| pause/resume | זמן מקור ותנוחות קפואים בהשהיה וממשיכים בניגון; אין זמן קיר לאנימציית הקהל |
| seek / משחק חדש | ניקוי המדידה הישנה וטעינת 22 שחקנים ב־0 של המשחק החדש |
| ניתוק אמיתי | הפקדים ננעלים, התמונה קופאת והודעת ניתוק גלויה גם כשכלי המציג סגורים; snapshot מחזיר פקדים ומנקה נתונים קודמים |
| אובדן context אמיתי | 2D fallback מסומן, סמל DOM נשאר; אין טענה שהגיבוי עומד בשער ביצועי 3D |

ביצועים עדכניים בחלון מוצג של שתי שניות: viewport ‏1280×850, canvas ‏1241×698, ‏DPR=1: ‏High ‏39–41FPS / ‏6.7–7.1ms draw; ‏Low ‏49–51FPS / ‏3.5–3.6ms. מדידה ראשונה של כ־20FPS נפסלה כמדידת baseline משום ששתי תצוגות תלת־ממד רונדרו במקביל; היא נרשמת כאן כדי לא להסתיר את השפעת העומס. אין כאן טענה למינימום 30FPS כאשר מפעילים שתי סצנות יחד, או ל־30 דקות soak. מדידת 1920×1080 במסמך D1-04 היא היסטורית עד לחזרה על המימוש העדכני.

## הכרעה ויומן למידה

תיקוני ההתנהגות נבדקו והוכחת הרגרסיה קיימת. עם זאת, **D1-04 לא הושלמה**: פרטי אצטדיון, חזרתיות צורות הקהל ואנימציית הכדורגל עדיין אינם ברמת תמונת הייחוס. נדרשת עבודת אמנות ואנימציה נוספת באותו branch/PR, ללא החלפת מקור האמת או רכישת נכסים. אין להסיק parity מצילום קטן או מספירת משולשים. אין לעבור למיזוג או לסמן את כל מסלול D1 כגמור כל עוד תנאי זה פתוח.

למידה להמשך: לבדוק reset על כל מצב נראה, כולל מדדים, פקד זמן ו־trace, ולא רק תנוחות וסמל; fake של DOM חייב לשמר את סמנטיקת ההעתקה האמיתית; למדוד עומס כשמספר סצנות הרינדור ידוע. כישלון ניסוי או מגבלת סביבה מתועדים בנפרד מכשל מוצר. אחריות התיקון: Codex, PR #12; אימות חוזר על SHA סופי ב־PR.
