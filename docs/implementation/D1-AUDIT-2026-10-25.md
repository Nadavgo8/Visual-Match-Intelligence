### המשך ליטוש באותו סשן — אטלס קהל

לאחר commit ‏`c48a3d2` (ארבעת checks עברו, Python ב־CI: ‏92.99% שורות / ‏88.24% ענפים; שורת Python הקריטית שהשתנתה 100%) בוצע ליטוש נוסף של אותו D1-04. הנכס `web/assets/crowd/spectators-v1.png` נוצר בכלי imagegen המובנה: ארבע דמויות אנונימיות סינתטיות, בשלוש תנוחות ובפנים ניטרליות. אלו תמונות על planes בתוך האצטדיון התלת־ממדי, ולא קהל של גופי אדם עם שלד. [הפרומפטים, שיטת ההפקה והמגבלות](../../web/assets/crowd/PROMPTS.md) נשמרו; SHA-256 ‏`190fabb67d1a8a3548aca1ca1ade033b4a4f5ea60dd8cc6b18ed785a51509c1f`. אין שימוש בצילום הייחוס כנכס, רכישה, CLI או API key.

גבולות alpha נמדדו בפועל; לא הונח שהמודל הפיק רשת מתמטית מושלמת. metadata נבדק לפני יצירת גאומטריה. alpha testing ו־depth writing מונעים מלבנים שקופים ומיון שקיפויות שגוי; gutter בין הדמויות מונע דגימת שכן. shared texture משוחררת פעם אחת בבעלות הסצנה, וגם במסלול כשל בהקמת WebGL. נתון הקהל המוחלק בוחר ישיבה/עמידה/ידיים מורמות, ו־Reduce motion משאיר ידיים למטה ומפסיק sway. אין שינוי ב־80/20 או שימוש בהתקפה לבחירת תנוחה.

מצלמת השידור הונמכה וקורבה כדי שהשחקנים והפעולה יהיו קריאים יותר. Full pitch והמצלמה הקבועה נשמרו. בדיקות גבולות הכדור ו־18 קווי הראייה עוברות. מספר המשולשים המדווח ב־High ירד מכ־3.46 מיליון לכ־1.26 מיליון, כולל מעברי הצללים; זה אינו תחליף למדידת FPS מחדש.

אימות אחרי השינוי: 82 Node עברו ב־5.55s; מודול האטלס 100% שורות וענפים בריצה מבודדת. כל 5 בדיקות API עברו ב־19.51s עם PNG, metadata ו־MIME החדשים; ruff ותחביר JS עברו. כל 20 התרחישים נבדקו שוב ב־renderer האמיתי עם 22 שחקנים והאטלס, ללא שגיאות JS. קהל 0/1/חסר והפחתת תנועה נבדקו מחדש. context loss אמיתי שמר את סמל DOM וניקה את כל אבחוני GPU הישנים. תוצאות החבילה המלאה והכיסוי על commit האטלס יירשמו ב־PR לאחר השלמת ה־CI; אין להעביר אליו אוטומטית את PASS של c48a3d2.

סקירת התצוגה לאחר מכן גילתה את D1-R25-05. נוסף מבחן קומפוזיציה בנוסף למבחן הכדור, והמצלמה תוקנה כך שהקהל נשאר חלק מרקע המשחק. צילום מוצר אמיתי אימת זאת. החבילה עלתה ל־83 בדיקות Node; ‏11 בדיקות התנועה/המצלמה/האצטדיון עברו, מול 9 הצלחות וכשל רגרסיה אחד לפני התיקון. הלמידה: בקומפוזיציה של מוצר נגיש צריך לבדוק גם את הקשר המידע שמסביב לפעולה, לא רק שהכדור בתוך המסך. ה־CI של 1a0f196 עבר כולו; גם commit תיקון המצלמה נדרש להרצה מלאה משלו.

תיקוני ההתנהגות נבדקו והוכחת הרגרסיה קיימת. עם זאת, **D1-04 לא הושלמה**: פרטי אצטדיון, חזרתיות צורות הקהל ואנימציית הכדורגל עדיין אינם ברמת תמונת הייחוס. נדרשת עבודת אמנות ואנימציה נוספת באותו branch/PR, ללא החלפת מקור האמת או רכישת נכסים. אין להסיק parity מצילום קטן או מספירת משולשים. אין לעבור למיזוג או לסמן את כל מסלול D1 כגמור כל עוד תנאי זה פתוח.

למידה להמשך: לבדוק reset על כל מצב נראה, כולל מדדים, פקד זמן ו־trace, ולא רק תנוחות וסמל; fake של DOM חייב לשמר את סמנטיקת ההעתקה האמיתית; למדוד עומס כשמספר סצנות הרינדור ידוע. כישלון ניסוי או מגבלת סביבה מתועדים בנפרד מכשל מוצר. אחריות התיקון: Codex, PR #12; אימות חוזר על SHA סופי ב־PR.
