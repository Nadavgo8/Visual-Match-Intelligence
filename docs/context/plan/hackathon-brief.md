# Microsoft Premier League Hackathon ("Inside the Game"): brief

Source: microsoft/insidethegamehackathon, `OFFICIAL RULES.md` (read 2026-10-08). The repo holds only the rules, a resource playlist, license, code of conduct and security notes. There is no starter code or dataset.

- **Submission closes: Tue Oct 27, 11:59 pm**
- Judging: Oct 27 to Nov 10. Winners announced by Nov 20.

## The challenge
Build an AI-driven app or agent system that turns **synthetic** football match events into explainable match intelligence. It should be one pipeline with five stages:
1. **Ingest** live synthetic events (passes, shots, tackles, possession changes, pressure, metadata)
2. **Interpret** them into stats, patterns and context
3. **Explain** why a moment matters (control vs chaos, pressure shifts, game rhythm)
4. **Render** it as something on screen next to the match, timed and machine-readable for overlays
5. **Personalize** it so an analyst and a casual fan get genuinely different experiences (favorite club or player, player-focus mode, language)

Suggested features: player tagging with speed and distance, pass distance, accuracy and difficulty, ball and shot speed, auto-eventing from video, narratives and recaps, multi-language output, and new synthetic datasets.

Real match footage or data is not provided and must not be used without rights. The data has to be synthetic.

## Deliverables
- A new project built after Sept 29, 2026
- A short pitch covering what it does, the problem it solves and which Microsoft/Azure tech it uses
- A demo video **under 2 minutes**, on YouTube or Vimeo, with no unlicensed music or trademarks
- A **public GitHub repo**
- A working test link (site, demo or build), free for judges through Nov 10
- Everything in English

## Judging
Stage 1 is a pass/fail check for fit with the theme and the required tech. Stage 2 has five equally weighted criteria at 20% each:
- **Technological implementation**: synthetic data creativity, code quality, and use of the hero tech (Foundry, Agent Framework, Azure MCP, GitHub Copilot agent mode, Fabric, GitHub SDK/CLI, Azure AI services and databases)
- **Agentic design and innovation**: orchestration, MCP, multi-agent work
- **Real-world impact**: could it run in production?
- **UX and presentation**: a polished demo video with a balance of frontend and backend
- **Category adherence**

Ties are broken in that order, so technological implementation counts first.

## Prizes

- Grand 2nd: ticket, voucher and $2,500 per member

## Eligibility
- Individuals of legal age, teams of up to 4 people, or organizations
- Excluded: residents of Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea, Sudan, Syria, and other OFAC-sanctioned places
- Excluded: employees of Microsoft or the Premier League, their affiliates, and their immediate families or households
- One person can be on several teams. Multiple entries are allowed if each one is substantially different.
